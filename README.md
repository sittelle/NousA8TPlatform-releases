# NOUS A8T Platform - releases and guide

Public downloads and the browser-only adoption guide for the NOUS A8T
platform. The firmware source itself lives in a separate, private repo;
this repo exists only to publish the guide (via GitHub Pages) and the
built release artifacts (via GitHub Releases) somewhere end users can
reach without repo access.

- **Guide**: https://sittelle.github.io/NousA8TPlatform-releases/
- **Downloads**: see [Releases](../../releases)
