# Relaywright - releases and guide

Relaywright is an independent, unofficial, community-built platform for the
NOUS A8T smart relay. It is not affiliated with, endorsed by, or supported
by NOUS, Bosch, or any other manufacturer named here.

Public downloads and the browser-only adoption guide for Relaywright. The
firmware source itself lives in a separate, private repo; this repo exists
only to publish the guide (via GitHub Pages) and the built release
artifacts (via GitHub Releases) somewhere end users can reach without repo
access.

- **Guide**: https://sittelle.github.io/Relaywright-releases/
- **Downloads**: see [Releases](../../releases)
